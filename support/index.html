回報問題時，建議附上

  1. 課時有數版本與 Build（可在「設定與工作室 → 關於課時有數 → 版本」查看）。
  2. 發生問題前正在做什麼，例如排課、完成課程、更正、續課、LINE 通報、備份或恢復。

常見問題

打開 LINE 就代表通報已送出嗎？

不是。課時有數只會把通報內容帶到 LINE／系統分享流程；最後是否送出由你在 LINE 中決定。課時有數不會把「成功打開 LINE」記錄為「已送出」。

課時扣錯了怎麼辦？

可依課程狀態使用 App 內提供的撤銷或更正功能。更正後會依目前產品邏輯恢復對應課時與歷史狀態。

備份包含什麼？

JSON 備份可能包含老師設定、學員、課包及課程記錄。請把備份視為私人課務資料，保存到可信位置，不要任意公開分享。

換手機或資料有問題時怎麼恢復？

在「設定與工作室」選擇「從 JSON 備份恢復資料」，再從 Apple「檔案」挑選有效備份。App 會先檢查資料並顯示預覽，經你再次確認後才取代目前本機資料。

課時有數會把學員資料傳到自己的伺服器嗎？

目前版本沒有課時有數自有帳號或雲端課務伺服器，主要業務資料保存在裝置本機。只有在你主動使用 LINE、系統分享或匯出備份時，資料才會依你選擇的外部服務處理。

目前有帳號登入或訂閱嗎？

目前版本不需要建立課時有數帳號，首發版本也沒有 App 內購買或訂閱功能。
