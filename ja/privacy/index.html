個人講師のレッスン管理 プライバシーポリシー

対象バージョン：1.2｜最終更新：2026年10月2日

個人講師のレッスン管理は、個人講師向けのローカル中心の生徒・レッスン管理アプリです。本ポリシーは現在のバージョンで作成・保存される情報の扱いを説明します。

1. 入力できる情報

講師・教室情報、生徒名や連絡メモ、科目・レベル、回数券、予定、レッスン記録、宿題、料金、訂正履歴などを入力できます。

2. 保存場所

現在のバージョンは独自アカウントを必要とせず、主要なレッスン管理データを受け取る開発者運営サーバーを使用しません。主要データは Apple 端末上のアプリ領域に保存されます。

3. 広告・追跡

現在のバージョンは第三者広告、広告追跡 SDK、第三者行動分析 SDK を組み込んでいません。

4. 共有

日本語・繁体字中国語のレッスン連絡では、ユーザーの明示操作で LINE の共有フローを開きます。LINE が開いたことだけで送信済みとは扱いません。共有後のデータは選択した外部サービスの規約・プライバシーポリシーに従います。

5. JSON バックアップと復元

Apple の「ファイル」を使って JSON バックアップを書き出し、選択した有効なバックアップから復元できます。復元前に内容を検証し、ユーザーの確認後に現在のローカルデータを置き換えます。

6. 保持と削除

ローカルデータは、ユーザーが変更・復元・アプリデータ削除・アプリ削除などを行うまで端末内に残ります。外部に保存したバックアップは、保存先でユーザーが管理します。

7. 未成年者に関する情報

本アプリは講師が自身のレッスン業務を管理するためのツールです。未成年の生徒情報を記録する場合は、レッスン管理に必要な範囲に限定し、必要な同意や法的根拠を確認してください。

8. お問い合わせ
