個人講師のレッスン管理 プライバシーポリシー

対象バージョン：個人講師のレッスン管理 1.3｜最終更新：2026年10月23日

個人講師のレッスン管理は、個人講師・家庭教師・コーチが生徒、回数券、予定、レッスン消化を管理するためのローカル中心のアプリです。本ポリシーは現在のバージョンで作成・保存される情報の扱いを説明します。

1. 入力できる情報

使い方に応じて、講師・教室情報、生徒名や連絡メモ、科目・レベル、回数券、予定、レッスン記録、宿題、料金、訂正履歴などのレッスン管理データを入力できます。

生徒、保護者、または未成年者に関する情報を記録する場合は、指導およびレッスン管理に本当に必要な範囲に限定し、ご利用地域の法令や契約関係に基づき必要な同意や法的根拠を確保してください。

2. 保存場所と端末バックアップ

現在のバージョンは独自アカウントを必要とせず、アプリ独自の iCloud／クラウド同期機能はなく、主要なレッスン管理データを受け取る開発者運営サーバーも使用しません。主要データは Apple 端末上のアプリ領域に保存されます。

ローカルデータベースは iOS の端末バックアップ対象から除外されていないため、ユーザー自身のバックアップ設定に応じて iPhone／iCloud の端末バックアップと一緒にバックアップされます。

3. レッスン管理データの収集有無

現在のバージョンは広告 SDK、第三者行動分析 SDK、追跡 SDK を組み込んでおらず、生徒やレッスン管理データを受け取る開発者運営のネットワーク API もありません。そのため、アプリ内のレッスン管理データが開発者や広告・分析パートナーのサーバーへ収集されることはありません。

4. LINE およびシステム共有

ユーザーが明示的に共有操作を行ったときにのみ、個人講師のレッスン管理は選択した連絡文面を iOS または LINE の共有・起動フローに渡します。LINE が開いたことだけで送信済みとは記録しません。個人講師のレッスン管理を離れた後のデータは、選択したシステムまたは外部サービスの規約・プライバシーポリシーに従って処理されます。

5. クリップボード

個人講師のレッスン管理は、ユーザーが明示的にコピー操作を行った場合、または LINE を正常に開けず画面上のコピー代替フローを使用した場合にのみ、連絡文面をシステムクリップボードに書き込みます。バックグラウンドで無断にクリップボードを読み取ることはありません。

6. JSON バックアップと復元

Apple の「ファイル」を使って JSON バックアップを書き出し、選択した有効なバックアップから復元できます。バックアップには講師、生徒、回数券、レッスンのデータが含まれる場合があるため、信頼できる保存先と共有相手を選択してください。

「ファイル」、iCloud Drive、その他の外部サービスに保存したバックアップの保持・削除は、ユーザー自身および各サービスの管理に従います。復元時には事前にデータ内容を検証してプレビューを表示し、ユーザーの確認後に現在のローカルデータを置き換えます。

7. アプリ内課金・購入の復元・既存ユーザー判定

個人講師のレッスン管理では、一回限りの買い切り・非サブスクリプション・自動更新なしのアプリ内課金「永久版」を提供しています。価格は各地域の App Store に表示される金額に準じます。決済および返金はすべて Apple によって処理され、アプリがカード番号などの決済情報に触れたり収集したりすることはありません。Apple 側で返金済みと記録された場合、永久版は無効になります。

バージョン 1.0、1.1、1.2 の既存ユーザー（1.3 へのアップデート後も無料で生徒数無制限を永久に維持）かどうかを判定するため、アプリは Apple が署名したダウンロード記録を Apple から読み取ります。確認する項目は環境、最初にダウンロードしたバージョン番号、App ID、Bundle ID のみであり、Apple ID、氏名、メールアドレスは読み取りません。この判定結果は端末のメモリ内でのみ使用され、ストレージへの保存やアップロードは行われません。一時的に読み取れない場合でも、利用を制限したり誤って課金を求めたりすることはありません。

課金画面と設定画面の両方に「購入を復元」を用意しており、ユーザー自身がタップしたときのみ Apple と同期します。その際、Apple アカウントのパスワード入力が必要になる場合があります。

8. 保持と削除

ローカルデータは、ユーザーがアプリ内で変更・バックアップによる上書き復元・端末やアプリデータの消去・アプリ削除を行うまで端末内に残ります。外部に書き出したバックアップや iPhone／iCloud の端末バックアップは、アプリ内のデータを削除しても自動では消えないため、「ファイル」や端末のバックアップ設定、各クラウドサービス側で管理してください。

現在のバージョンには個人講師のレッスン管理のサーバー側アカウントが存在しないため、開発者に削除を申請すべきサーバー上のアカウントデータもありません。

9. 追跡・広告・分析

  • 現在のバージョンは第三者広告を表示しません。
  • 広告追跡 SDK を組み込んでいません。
  • 第三者行動分析 SDK を組み込んでいません。
  • ユーザーのデータを他社アプリや Web サイトをまたぐ広告追跡プロファイルの作成に利用しません。

10. 未成年者に関する情報

個人講師のレッスン管理は講師自身が自分のレッスン業務を管理するためのツールであり、子ども向けにアカウント、SNS、広告サービスを提供するアプリではありません。未成年の生徒情報を記録する場合は、レッスン管理に必要な範囲に限定し、業務と無関係な機微情報の記録は避けてください。

11. セキュリティ

個人講師のレッスン管理は、ローカル優先設計、データ送信の最小化、管理されたバックアップ復元とデータ整合性チェックによりリスク低減を図っています。いかなる保存方法も完全な安全を保証するものではないため、端末の画面ロックを適切に設定し、書き出したバックアップファイルを安全に管理してください。

12. ポリシーの更新

現在のバージョンには Apple が決済を処理する買い切りの「永久版」アプリ内課金が含まれていますが、開発者が運営する課金バックエンド、アカウント機能、クラウド同期、第三者分析は引き続きありません。将来のバージョンでアカウント、クラウド同期、第三者分析、課金バックエンドなどデータの取扱いを変更する機能を追加する場合は、実際のバージョンに合わせて本ポリシーおよび App Store のプライバシー表示を更新します。
